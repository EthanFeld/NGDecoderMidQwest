# Tensor search engine

Internal Python and native support for the telescope decoder. The engine builds
complete-fault probability tables, conditions matching weights on the opposite
check basis, and compares physical witnesses in both logical sectors. Two
starting orders and two refinement iterations form the default search rule.

The telescope injects its independent matching engine through `matching_engine`.
The retained reference factory and private small-code kernels support historical
replay. CPU and NVIDIA FP64 conditioning share the same decision rule.

Install the parent project with `python -m pip install -e ./decoders/telescope`
from the repository root. See the [telescope guide](../README.md),
[source](src/tensor_decoder/), [records](results/README.md) and
[third-party attribution](THIRD_PARTY.md).
