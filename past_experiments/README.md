| Folder | Contents |

| [surface_fpga](surface_fpga/README.md) | Distance-3 MAP, distance-7/distance-15 prior tilt, rescue and weighted-growth FPGA designs. |
| [tang_nano_20k_d15](tang_nano_20k_d15/README.md) | Selective graph-rule distance-15 FPGA decoder and software reference. |

| [fpga_benchmark](fpga_benchmark/README.md) | FPGA packet generation, UART capture and replay tools. |
